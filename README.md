# React + TypeScript + Vite

Agregar el archivo `.env` al repositorio en la carpeta `backend`, donde se definan las variables MONGODB_URI y PORT.

Dentro de la carpeta `frontend` correr el siguiente comando para instalar las dependencias del proyecto.

```
npm install
```

Para correr el `frontend` se necesita el comando

```
npm run dev
```

Para correr el `backend` se necesita el comando

```
npx ts-node src/index.ts
```
